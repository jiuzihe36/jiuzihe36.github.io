把静态博客部署到 GitHub Pages

GitHub Pages 对个人项目几乎零成本，而且原生支持自定义域名。下面是标准流程。

两种仓库形态

  • 用户页：仓库名必须为 <用户名>.github.io，内容直接作为站点根
  • 项目页：任意仓库，可在 Settings → Pages 中选择分支与目录

部署步骤

  1. 在仓库根目录放好构建好的静态文件（index.html 等）
  2. 进入仓库 Settings → Pages
  3. 选择 Deploy from a branch，分支选 main，目录选 / (root)
  4. 保存后等待一两分钟，访问 https://<用户名>.github.io

提示：如果你用的是项目页，文章链接和 RSS 里的基地址要带上仓库名这个子路径。

常见坑

  • 资源（CSS/JS）用了绝对路径 /assets/...，在子路径下会 404 —— 用相对路径或配置 baseUrl
  • 忘记提交 assets/ 目录，页面没有样式
  • 自定义域名后没加 CNAME 文件，下次部署被覆盖

部署本身很简单，难的是把「可重复」这件事固化成习惯。
